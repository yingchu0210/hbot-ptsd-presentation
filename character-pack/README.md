# 好運來蕃茄園・三位角色包

爸爸「運來」、媽媽、女兒的 Q 版卡通角色。可分離成「身體／手臂／頭／表情」圖層，可直接用於另一支歌曲 MV。

> 角色是依外型特徵畫成的原創卡通，不是寫實肖像。三位本人已同意用於「好運來小番茄」MV；若另一支 MV 用途不同，建議再向本人確認一次。
> 提供給我的真人照片**沒有**放進這個資料夾，只保留最後確認的卡通版本。

## 快速開始

1. 用瀏覽器開 `viewer.html`，確認三位角色都正常。
2. 在你的專案裡用 `code/puppet.js`：

```html
<script src="code/puppet.js"></script>
<script>
  const p = createPuppet(document.body, 'girl', { scale: 0.4, base: 'rig/' });
  p.set({ expr: 'happy', left: [0, 'fist'], right: [105, 'thumb'], tilt: 3, flip: false });
</script>
```

- `key`：`dad`、`mom`、`girl`
- `expr`：`smile`、`happy`、`laugh`、`shy`、`sad`、`wow`
- 手勢：`fist`（握拳／垂放）、`open`（張開／揮手）、`thumb`（比讚）
- 角度：`0` 手自然下垂、`90` 水平外伸、`150` 高舉；左臂用 +角度、右臂用 −角度（程式已處理，直接給正數即可）
- 動畫時每格更新 `set()` 即可：身體彈跳可對整個 `p.el` 做位移，頭部傾斜用 `tilt`

## 圖層疊放順序（自己拼裝時）

所有圖層的畫布大小一樣，身體／頭／表情／圍巾直接疊在 (0,0) 即可對位：

1. `身體`（`<角色>_body.svg`）
2. `左臂`、`右臂`（`<角色>_armL_<手勢>.svg`、`..._armR_...`）：**以肩膀樞紐為原點**，旋轉中心 `(170, 110)`
3. `圍巾`（只有女兒，`girl_scarf.svg`）：蓋在手臂上面
4. `頭`（`<角色>_head.svg`）：旋轉中心是脖子樞紐
5. `表情`（`<角色>_face_<表情>.svg`）：跟頭一起轉

各角色的畫布大小、樞紐座標、色碼都在 `characters.json`。

## 角色設定

**爸爸「運來」**：番茄園主人，「好運來」的名字就是他的名字。頭頂光亮，兩側與耳後是毛茸茸的銀白短髮；灰色粗眉、小眼睛、眼角魚尾紋，圓潤臉頰帶紅暈。藍色寬鬆圓領 T 恤、灰色長褲、棕色工作鞋。招牌動作：摘下番茄在衣服上擦一擦就直接吃。

**媽媽**：用鮮牛奶加自家實驗多年的天然配方澆灌小番茄。粉紅寬簷遮陽帽、白色下巴繫帶、兩側粉紅布簾，帽下是淺棕色捲髮，笑瞇瞇。青綠長袖衫配蝴蝶圖案、深藍防曬袖套、灰紫色工作手套，淺藍花葉紋長褲、白色球鞋。

**女兒**：從台北回高雄當後援，架起 LINE 官方帳號。深褐色及下巴鮑伯，中分、細瀏海，耳朵露出；臉寬而圓，粉紅腮紅。粉紅羽絨外套（格子絎縫）、橘紅流蘇圍巾、黑色斜背小包、深色長褲、白色球鞋。

**品牌背景**：好運來蕃茄園（高雄美濃），專賣橙蜜香與玉女小番茄。標語「吃顆好運來，好運一直來」。

## 已知限制

- **只有正面**，沒有側面、背面或 3/4 角度。
- **腿不能動**：身體是一整片（含腿），不能做走路的腿部動作；移動請用整體位移加上下彈跳。
- **女兒的眉毛不會動**：原圖的眉毛是夾在瀏海裡的細線，擦掉會弄髒頭髮，所以保留原圖眉毛；她的擔憂、驚喜靠眼睛和嘴巴表現。
- **補畫的部分是近似的**：手臂原本擋住的身體（袖口、肩線、外套格紋、斜背包），是用同色塊和線條補的，放很大時細節比原圖粗糙。
- **手是重畫的**：三種手勢（握拳、張開、比讚）是程式畫的，畫風比原圖簡單。
- **表情是疊上去的新畫版本**：原圖臉上的眼睛、嘴巴已用膚色蓋掉，改由 6 種表情圖層提供；所以不能再用原圖的表情。
- **紅、橙兩隻番茄吉祥物不在這個資料夾**，程式碼在 `lucky-tomato-mv-src/kit.js` 的 `mascotSVG`。
