# 好運來蕃茄園・三位角色

使用者要製作用到爸爸「運來」、媽媽、女兒的 MV／動畫／插畫時，先做這幾件事，再開始畫或做。

## 1. 先讀角色包（不要憑印象畫）

依序讀取，路徑相對於儲存庫根目錄：

1. `character-pack/README.md`：內容、圖層疊放順序、轉軸座標、已知限制。
2. `character-pack/characters.json`：畫布大小、肩膀／脖子樞紐、配色色碼、外型特徵、品牌背景。
3. 需要看樣子時，看 `character-pack/sheets/設定圖-三人群像.png` 和各人的設定圖，或用瀏覽器開 `character-pack/viewer.html`。

## 2. 怎麼用素材

- **動畫**：用 `character-pack/rig/` 的分層 SVG 和 `character-pack/code/puppet.js`（免函式庫）。
  - 表情：`smile`、`happy`、`laugh`、`shy`、`sad`、`wow`
  - 手勢：`fist`（垂放）、`open`（揮手）、`thumb`（比讚）
  - 角度：0 下垂、90 水平、150 高舉；左臂 +角、右臂 −角
- **靜態圖／海報**：用 `character-pack/vector/` 的整張向量圖，或 `character-pack/reference/` 的原圖。
- **畫風一致**：MV 的配色、字體（Huninn 粉圓）和元件規範見 `lucky-tomato-style-guide.png`；程式碼參考 `lucky-tomato-mv-src/`。
- **番茄吉祥物**（紅色玉女、橙黃橙蜜香）不在角色包內，程式碼在 `lucky-tomato-mv-src/kit.js` 的 `mascotSVG`。

## 3. 一定要遵守

- 角色是**原創卡通**，只保留外型特徵，**不要畫成寫實肖像**，也不要拿真人照片描圖。
- 不要擅自改角色外型（髮型、臉型、服裝、配色）；要改先問使用者。
- 已知限制：只有正面、腿不能動、女兒的眉毛不會動、補畫的身體放大後較粗糙、三種手勢畫風比原圖簡單。需要側面或走路時，先告訴使用者做不到，再提替代方案。
- 三位本人同意的範圍是「好運來小番茄」MV；另一支 MV 若用途不同，提醒使用者再向本人確認。

## 4. 品牌背景（寫歌詞、字幕、故事時用）

- 好運來蕃茄園（高雄美濃），專賣橙蜜香與玉女小番茄。
- 名字由來：爸爸的名字叫「運來」。
- 標語：「吃顆好運來，好運一直來」。
- 故事：爸媽曾因連日大雨和通路不穩停種兩三年，被老客人敲碗敲回來；媽媽用鮮牛奶加自家配方灌溉；女兒從台北回高雄當後援、架起 LINE 官方帳號。
- 資料來源以使用者提供的粉專貼文為準，不要自行編造產地或品種資料。

## 5. 開始前向使用者確認

簡短問清楚：這支 MV 的歌（有無 mp3 與歌詞）、畫風是否沿用上一支、片長與比例、需要哪些角色出場。
